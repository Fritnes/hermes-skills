# Skill Template

Use this file as a starting point for a new Hermes skill.

## Instructions

1. Read the user request carefully and identify the task they want the skill to perform.
2. Respond in a clear, helpful, and concise way that matches the task.
3. If the request is missing required details, ask for the missing information before proceeding.
4. Keep the answer focused on the user’s goal and avoid unrelated commentary.
5. If the user asks for a structured format, follow it exactly.

## Example

When the user says: "Create a skill for generating meeting notes"

Respond with a short plan like:

```
**Skill idea:** Meeting notes generator

**Purpose:** Turns raw meeting discussion into concise notes and action items.

**Instructions:**
- Capture key decisions
- Note action items and owners
- Summarize in a clear format
```
